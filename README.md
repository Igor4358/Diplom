🚚 ТСД Автосклад — Терминал сбора данных для склада автозапчастей
Веб-приложение (PWA) для автоматизации складских операций: приёмка товара, сборка заказов, сортировка, перемещение между складами и работа с упаковками. Разработано как дипломный проект и адаптировано под реальные процессы склада автозапчастей.

🚀 Установка и запуск
Требования
.NET 8 SDK

PostgreSQL 16

Visual Studio 2022 (или VS Code)

Node.js (для localtunnel)

Шаг 1. Клонировать репозиторий
bash
git clone https://github.com/your-username/wms-terminal.git
cd wms-terminal
Шаг 2. Настроить подключение к БД
Откройте appsettings.json и укажите строку подключения:

json
{
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Database=WMS_Terminal;Username=postgres;Password=ваш_пароль"
  }
}

Шаг 3. Применить миграции

bash
dotnet ef database update

Шаг 4. Запустить проект

bash
dotnet run --urls="http://0.0.0.0:5000"
Приложение будет доступно по адресу: http://localhost:5000

📱 Запуск на телефоне (HTTPS-туннель)
Для тестирования сканера через камеру телефона используется localtunnel — он создаёт публичный HTTPS-адрес.

Терминал 1 — запуск сервера
bash
dotnet run --urls="http://0.0.0.0:5000"
Терминал 2 — создание туннеля
bash
npm install -g localtunnel
lt --port 5000 --subdomain mywmsapp
Результат
Откройте на телефоне:

text
https://mywmsapp.loca.lt
Важно: браузеры разрешают доступ к камере только через HTTPS, поэтому без туннеля сканер на телефоне не заработает.

Алгоритм EAN-13 (контрольная сумма)
csharp
private string GenerateEan13Barcode()
{
    var random = new Random();
    var digits = string.Join("", Enumerable.Range(0, 12)
        .Select(_ => random.Next(0, 10).ToString()));
    
    int sum = 0;
    for (int i = 0; i < 12; i++)
    {
        int digit = int.Parse(digits[i].ToString());
        if (i % 2 == 0) sum += digit;
        else sum += digit * 3;
    }
    int checkDigit = (10 - (sum % 10)) % 10;
    
    return digits + checkDigit.ToString();
}
Зачем нужна контрольная сумма: сканер проверяет правильность чтения кода. Если одна цифра прочитана неверно — код не будет принят.
